# CK444 Aviator Tracker (PWA) - পরিসংখ্যান ট্র্যাকার

**এটি ভবিষ্যদ্বাণীর টুল নয়।** আপনি গেম স্ক্রিনে দেখা মাল্টিপ্লায়ার নিজে লেখেন; অ্যাপ সেগুলো ফোনেই সংরক্ষণ করে এবং পরিসংখ্যান দেখায়।
অতীত ফলাফল ভবিষ্যৎ ফলাফলের নিশ্চয়তা দেয় না। কোনো লাভের বা নির্ভুল সিগনালের নিশ্চয়তা নেই। অ্যাপ কোনো গেম সার্ভার/RNG ডেটা পায় না।

*This is a statistics tracker, not a prediction tool. No guaranteed signals or profits.*

## ফাইল (সবগুলো একই ফোল্ডারে, কোনো সাব-ফোল্ডার নেই)
| ফাইল | কাজ |
|---|---|
| index.html | পেজের কাঠামো |
| style.css | ডার্ক লাল-কালো-সাদা ডিজাইন |
| app.js | সব লজিক (এন্ট্রি, এডিট/ডিলিট, পরিসংখ্যান, চার্ট, সিগনাল টেস্ট, CSV) |
| manifest.json | PWA/ইন্সটল তথ্য |
| service-worker.js | অফলাইনে চালানোর ক্যাশ |
| icon-192.png, icon-512.png | অ্যাপ আইকন (সাধারণ প্লেসহোল্ডার) |
| tests/logic.test.js | ঐচ্ছিক টেস্ট (কম্পিউটারে `node tests/logic.test.js`) |

## অ্যাপে কী আছে
- **Dashboard:** মোট রাউন্ড, গড়, 2x এর নিচে %, 2x বা বেশি %, সাম্প্রতিক ১০টি।
- **History:** সব এন্ট্রি (সময়সহ), এডিট ও ডিলিট।
- **Analysis:** median, min/max, বণ্টন চার্ট, শেষ ৫০ রাউন্ডের লাইন চার্ট, বর্ণনামূলক সূচক, পরীক্ষামূলক সিগনাল।
- **Settings:** ভাষা (বাংলা/English), ডেটা সেট (আসল/ডেমো), CSV এক্সপোর্ট, সব ডেটা মুছা (নিশ্চিতকরণসহ)।

### সিগনাল মডিউল কীভাবে সৎ থাকে
- নিয়ম: টানা k টি রাউন্ড 2x এর নিচে হলে "পরের রাউন্ড 2x+" সিগনাল। প্রতিটি টেস্ট শুধু আগের ডেটা ব্যবহার করে।
- ৫০টির কম রাউন্ডে **"পর্যাপ্ত ডেটা নেই"**; ৩০টির কম পরীক্ষিত সিগনালে নির্ভুলতা দেখায় না।
- দেখায়: পরীক্ষিত সংখ্যা, সঠিক, ভুল, নির্ভুলতা, ৯৫% অনিশ্চয়তা সীমা, এবং **তুলনার ভিত্তি হার**। কোনো সংখ্যা বানানো বা আগে থেকে ধরা নেই; সবকিছু আপনার ডেটা থেকে হিসাব হয়।
- Aviator-এর মতো গেমে প্রতিটি রাউন্ড স্বাধীন। তাই ভালো টেস্ট করলেও সাধারণত ভিত্তি হারের চেয়ে আলাদা কিছু পাওয়া যাবে না। এটাই প্রত্যাশিত।

### ডেমো ডেটা
Settings থেকে নিশ্চিত করে লোড করলে ২০০টি **কৃত্রিম** সংখ্যা আলাদা "ডেমো" সেটে যায়। স্ক্রিনে লাল ব্যানার ও ডেমো ব্যাজ থাকে। আসল ডেটার সাথে কখনো মিশে না।

### লাইভ স্ক্রিন রিডিং (OCR)
এই PWA অন্য অ্যাপের স্ক্রিন পড়তে পারে না (Android Chrome-এ এটা সমর্থিত নয়)। ভবিষ্যতে আলাদা Android অ্যাপে MediaProjection (ব্যবহারকারীর স্পষ্ট অনুমতিসহ) + অন-ডিভাইস OCR দিয়ে চেষ্টা করা যেতে পারে, তবে এখানে বানানো হয়নি। লগইন/নিরাপত্তা/অ্যান্টি-বট এড়ানো হবে না; সার্ভারের ডেটা পাওয়ার দাবি করা হবে না; সাইটের নিয়মও দেখতে হবে। নির্ভরযোগ্য উপায় হলো ম্যানুয়াল এন্ট্রি।

## শুধু Android ফোন দিয়ে চালানো ও পাবলিশ

### ধাপ ১: ফাইল ফোনে নিন
1. ZIP ডাউনলোড করুন, Files অ্যাপে ZIP-এ চেপে **Extract** করুন।
2. ভেতরে ৮টি ফাইল পাবেন (`index.html`, `style.css`, `app.js`, `manifest.json`, `service-worker.js`, `README.md`, `icon-192.png`, `icon-512.png`)।

### ধাপ ২: GitHub-এ আপলোড (Chrome ব্রাউজার দিয়ে)
> GitHub অফিসিয়াল Android অ্যাপ দিয়ে একসাথে অনেক ফাইল/ছবি আপলোড করা যায় না (অ্যাপটি দেখা ও ছোট এডিটের জন্য ভালো)। তাই আপলোড হবে Chrome দিয়ে।
1. Chrome-এ github.com খুলে লগইন করুন (অ্যাকাউন্ট না থাকলে ফ্রি খুলুন)। ⋮ মেনু থেকে **Desktop site** চালু করুন।
2. **New repository** চাপুন। নাম `ck444-tracker`, **Public**, **Create repository**।
3. **uploading an existing file** চাপুন, **choose your files** চেপে Extract করা ফোল্ডার থেকে ৮টি ফাইল একসাথে বেছে নিন (একটাতে লং-প্রেস করে বাকিগুলো সিলেক্ট)।
4. নিচে **Commit changes** চাপুন।

### ধাপ ৩: GitHub Pages চালু
1. রিপোজিটরির **Settings → Pages** এ যান।
2. **Source: Deploy from a branch**, **Branch: main**, ফোল্ডার **/ (root)**, তারপর **Save**।
3. ১–২ মিনিট পরে পেজ রিফ্রেশ করলে লিংক আসবে: `https://আপনার-ইউজারনেম.github.io/ck444-tracker/`

### ধাপ ৪: ফোনে ইন্সটল
1. Chrome-এ ওই লিংক খুলুন।
2. ⋮ মেনু → **Add to Home screen / Install app**। হোম স্ক্রিনে আইকন আসবে এবং অফলাইনেও চলবে।

### আপডেট করতে
GitHub-এ ফাইল খুলে ✏️ এডিট করে Commit করুন (অথবা নতুন ফাইল আবার আপলোড করে একই নামে Commit করুন)। এক-দুই মিনিটে লাইভ হবে।

## শুধু লোকালি চালানো (ইন্টারনেট ছাড়া টেস্ট)
- সহজ: GitHub Pages লিংক একবার খুললেই অফলাইন ক্যাশ হয়ে যায়।
- Termux (F-Droid থেকে) থাকলে: ফোল্ডারে গিয়ে `python -m http.server 8000`, তারপর Chrome-এ `http://localhost:8000`।
- `index.html` সরাসরি ফাইল হিসেবে খুললেও সাধারণ ফিচার চলে, কিন্তু অফলাইন ক্যাশ/ইন্সটল কাজ করবে না।

## পরে APK বানানোর পথ
1. **সবচেয়ে সহজ:** "Add to Home screen" দিয়ে ইন্সটল করা PWA ইতিমধ্যে অ্যাপের মতোই চলে।
2. **APK ফাইল:** GitHub Pages লিংক নিয়ে ফোনের ব্রাউজারে pwabuilder.com খুলে Android প্যাকেজ বানানো যায় (Trusted Web Activity)। এর জন্য সাইনিং কী লাগে; প্রথমবারে ধাপগুলো কঠিন মনে হলে আমাকে বলুন।
3. **ভবিষ্যতে:** Capacitor দিয়ে GitHub Actions-এ ক্লাউডে APK বানানো যায় (আগের প্রজেক্টের মতো), কম্পিউটার লাগে না।

## টেস্ট চেকলিস্ট
1. `abc` লিখে যোগ করুন, ভুল-বার্তা আসা উচিত।
2. `1.25x`, `2.40x`, `5.60x` যোগ করুন, মোট ৩, গড় 3.08x।
3. পেজ রিফ্রেশ করুন, ডেটা থাকা উচিত।
4. History-তে এডিট ও ডিলিট করুন।
5. Settings → ডেমো লোড, ব্যানার দেখা যাবে; "আসল" সেটে ফিরলে আসল ডেটা অক্ষত।
6. CSV এক্সপোর্ট করে ফাইল দেখুন।
